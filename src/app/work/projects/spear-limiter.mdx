## Overview

**Spear Limiter** adalah tool command-line untuk penemuan perangkat dan pengujian kontrol koneksi berbasis ARP pada jaringan lokal. Proyek ini ditujukan untuk pembelajaran serta pengujian keamanan dengan izin.

## Problem

Alamat IP dan MAC saja belum cukup untuk mengenali perangkat. Pengujian juga membutuhkan kontrol terhadap perilaku koneksi dan penanganan perubahan jaringan saat sesi berakhir.

## Key Features

- **Identifikasi berlapis**: Memperkaya hasil pemindaian melalui DHCP pasif, mDNS, reverse DNS, NetBIOS, dan inferensi vendor MAC.
- **Kontrol koneksi**: Menyediakan mode pemutusan koneksi dan mode pemblokiran UDP dengan mempertahankan TCP.
- **Pengujian beberapa perangkat**: Mendukung operasi pada perangkat aktif dalam subnet, dengan jeda antar-target.
- **Penutupan sesi**: Menyediakan mekanisme pemulihan ARP dan pembersihan aturan firewall ketika dihentikan melalui Ctrl+C.

## Technologies Used

- **Python** untuk logika aplikasi dan antarmuka CLI.
- **Scapy** untuk operasi paket jaringan dan ARP.
- **Linux & iptables** untuk pengaturan trafik pada mode pemblokiran UDP.

## Engineering Considerations

Identifikasi host menggabungkan beberapa sumber karena setiap perangkat dapat memberikan informasi berbeda. Hasilnya perlu dibaca sebagai petunjuk identitas, bukan jaminan identifikasi mutlak.

Pengelolaan siklus sesi juga penting: perubahan koneksi harus disertai mekanisme pemulihan, bukan hanya berfokus pada keberhasilan pemblokiran.

## Outcome

Proyek ini menyatukan penemuan perangkat dan kontrol koneksi dalam satu CLI, sekaligus menjadi eksplorasi pemrograman jaringan dan pengelolaan trafik.
